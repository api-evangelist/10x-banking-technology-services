# 10x Banking Technology Services

> Cloud-native core banking platform (SuperCore / "meta core") from a London-headquartered
> vendor founded by former Barclays CEO Antony Jenkins. It runs retail, business, corporate
> and embedded-finance banking for institutions including Chase UK, Westpac, Old Mutual,
> The Co-operative Bank and West Brom Building Society. Sold as an API-first managed core:
> banks configure banking products rather than rebuild them, and extend the core through the
> ProductKit SDK, APIs, templates, console and CLI tooling.

## Read this first: the API is not publicly documented

10x Banking's developer documentation and API contract are NOT public. Every path on
docs.10xbanking.com returns HTTP 302 to a ReadMe login (dash.readme.com/to/docs-10xbanking),
and every path on the API host returns HTTP 401. As of 2026-09-05 there is no published
OpenAPI, AsyncAPI, GraphQL SDL, WSDL, Protobuf, MCP server, agent card or llms.txt.

If you are an agent asked to call the 10x Banking API: you cannot, without tenant
credentials issued under a platform agreement. Do not guess endpoint paths — the API host
returns the same 401 for real and non-existent paths, so a 401 tells you nothing about
whether a path exists.

## API surface

- 10x Banking Platform API — https://docs.10xbanking.com/ (login-gated)
  - Sandbox base URL: https://api.sandbox.10xbanking.com (returns 401 to every anonymous
    request; source: 10x's own public Postman environment)
  - Production base URL: not published; appears to be tenant-specific
  - Error envelope: proprietary JSON `{ ref, status, code, message }` with dotted numeric
    codes (observed: 401.002.001). Not RFC 9457.
  - Authentication: undisclosed. No WWW-Authenticate header, no OAuth or OpenID discovery
    document on any host.

## Domain vocabulary

Read from 10x's own public Postman environment — the only first-party machine-readable
artifact 10x publishes. These are entity keys the API addresses, not operation names:

party, business party, arrangement (overdraft, secured loan, unsecured loan, credit card),
subscription (transaction account, deposit account, loan account, term maturity, credit
card), product (transaction, deposit, loan, term maturity, credit card — each with version
and currency), transaction, repayment schedule, debit/credit interest override, card,
statement, sweep, notice, document, case, dispute, conversation, collateral, correlation key.

## Not published

No pricing or plans page (404 on /pricing). No status page (status.10xbanking.com does not
resolve). No public changelog, versioning policy, deprecation policy or SLA. No GitHub
organisation. No client SDK on npm, PyPI, Maven Central, NuGet, RubyGems, pkg.go.dev,
Packagist or crates.io — the ProductKit SDK is distributed to tenants only. No rate limits
documented and no rate-limit response headers observed. No trust centre or published
security certifications.

## Standards

Open banking conformance for 10x deployments is delivered by a partner overlay (Ozone API,
https://www.10xbanking.com/partner-ozone-api), not by a 10x contract. No domain standard
(ISO 20022, BIAN, OBIE, FDX) could be verified, because there is no contract to read.
